# tools/stage1/eventbuffer_manifest.py drops every other branch named HLT_* or L1_* from the branch
# union before the header is generated. Reason: the HLT menu changes from run to run, so the HLT
# branch set changes from file to file (2024: 270 to 280 per era, and inside era C and I), and
# treestream takes the branch set of a chain from its FIRST file (PLAN 9.3). The analysis reads only
# the paths below; Flag_*, objects, weights and everything else stay as they are.
#
# One name per line; '#' starts a comment. A name may be absent from some inputs (it is then 0 =
# "did not fire" in those files, which is right when the path did not exist there) but must be in at
# least one input, or the manifest lists it as WARN. Every HLT name the analyzer source reads
# (_ev->HLT_... or "Events/HLT_...") must be here, or the manifest stops (exit 1): the header would
# not have the member and the build would fail.
